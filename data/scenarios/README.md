# Test scenarios

Each folder holds `problem.md` (what the engineer types), `logs/` (synthetic, anonymized log extracts) and `expected.json` (labels).
These are the Week 3 demo cases and the first part of the Week 4 golden dataset.

`expected_route`: `known_fix` (strong knowledge-repo match), `similar` (partial match, confirm with docs), `new_issue` (vendor-doc research), `clarify` (not enough information).
