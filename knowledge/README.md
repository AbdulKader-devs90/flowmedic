# Knowledge repo

- `incidents/` solved incidents (YAML front matter + Symptoms, Root cause, Resolution steps, Verification)
- `runbooks/` diagnostic and recovery runbooks (YAML front matter + steps tagged [read] or [change])
- `categories.yaml` the fixed triage labels
- `root_causes.yaml` controlled root-cause IDs used by incidents, scenarios and evals

All content is synthetic or anonymized. New incidents are added only after an engineer approves them.
