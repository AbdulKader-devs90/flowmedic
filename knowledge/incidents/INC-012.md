# INC-012 Gateway returns 504 because the IS service is slower than the gateway timeout

## Symptoms

One partner API returns 504 from the gateway after 30 seconds; IS logs show the service completing in 35-40 seconds.

## Root cause

The backend behind the IS service slowed down; the gateway read timeout (30 s) is shorter than the service time.

## Resolution steps

1. [read] Compare gateway timeout with IS service duration for the same calls.
2. [read] Check the backend response time behind the service.
3. [change] Fix the backend slowness first; raise the gateway timeout only with the API owner's approval.

## Verification

No 504s for that API; p95 under the timeout.
