# INC-007 CPU saturation from per-call Basic auth hashing

## Symptoms

CPU at 100% on both IS nodes; thread dumps show most HTTP handler threads in PBKDF2KeyImpl.deriveKey; calls come from the gateway.

## Root cause

The gateway sends Basic auth on every call and IS hashes the password each time; traffic growth made this the bottleneck.

## Resolution steps

1. [read] Count threads in deriveKey across 2 thread dumps.
2. [read] Gateway analytics: top APIs by calls.
3. [change] Throttle the heaviest APIs at the gateway.
4. [change] Plan mTLS or token-based auth between gateway and IS.

## Verification

CPU back to normal; deriveKey threads near zero.
