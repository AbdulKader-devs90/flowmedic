# INC-014 Partner token rejected on one node after restart

## Symptoms

After is-node-a restarted, one partner gets 401 on half its calls; is-node-b accepts the same token.

## Root cause

Tokens issued before the restart were held in node memory; the restarted node no longer knew them.

## Resolution steps

1. [read] Identify which node rejects; check the rejected calls in server.log.
2. [read] Compare auth settings and clock on both nodes.
3. [change] Ask the partner to request a new token and resubmit.
4. [change] Move token state to a shared store or use stateless tokens.

## Verification

No 401s for that partner for 30 minutes.
