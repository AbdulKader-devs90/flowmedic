# INC-011 Heap OutOfMemoryError from a large batch payload

## Symptoms

IS restarts by itself at night; wrapper.log shows java.lang.OutOfMemoryError: Java heap space during a bulk file job.

## Root cause

A batch service loaded a 900 MB file into memory as one document instead of streaming it.

## Resolution steps

1. [read] Find the OOM time in wrapper.log and the service running then.
2. [read] Check heap size against host RAM.
3. [change] Change the service to stream or split the file.
4. [change] Schedule the job away from peak traffic until fixed.

## Verification

Job completes; no OOM in wrapper.log.
