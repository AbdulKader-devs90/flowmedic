# INC-008 Terracotta active swap causes IS cache rejoin

## Symptoms

IS logs cache put timeouts (ISS.0033.0154E) and rejoin messages; the active Terracotta server changed; tsa-2 host swapping.

## Root cause

The Terracotta host ran out of RAM and swapped, stalling the active server; the passive took over and IS rejoined the cluster.

## Resolution steps

1. [read] Check status of both Terracotta servers (active-coordinator and passive-standby).
2. [read] Check swap on both Terracotta hosts.
3. [read] If IS reconnected after startup, watch: IS rejoins on its own.
4. [change] If stuck: stop passive then active; start the intended active first, then the passive; then restart IS per RB-14.
5. [change] Size Terracotta heap and host RAM so it never swaps.

## Verification

One active, one passive; no new 0154E.
