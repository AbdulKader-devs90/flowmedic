# INC-002 JDBC adapter fails after DB password rotation

## Symptoms

All services using one adapter connection fail with ART.118.5053 right after a scheduled DB password change.

## Root cause

The DB team rotated the service account password; the adapter connection still had the old one, and repeated failures locked the account.

## Resolution steps

1. [read] Check server.log for ORA-01017 (invalid username/password) next to ART.118.5053.
2. [read] Ask the DBA whether the account is locked.
3. [change] DBA unlocks the account.
4. [change] Update the password in the adapter connection, then disable and enable it.

## Verification

Adapter service runs; no new ART.118.5053 for 15 minutes.
