# INC-015 Package fails to load after deploy: missing dependency

## Symptoms

After a deploy, the OrdersApi package shows as not loaded and its services return 'not found'.

## Root cause

The package declared a dependency on a utility package version that was not deployed to production.

## Resolution steps

1. [read] Check server.log for the package load error and the dependency it names.
2. [read] Compare the deployed package versions with the release list.
3. [change] Deploy the missing dependency, then reload the package.

## Verification

Package loads; services respond.
