# INC-013 Backend connection refused after the backend moved port

## Symptoms

Repeated 'Connection refused' to one backend from every IS node since a backend release.

## Root cause

The backend team moved the service to a new port; the IS endpoint alias still pointed to the old port.

## Resolution steps

1. [read] Test the backend host and port from the IS host (curl or nc, read only).
2. [read] Compare the IS endpoint alias with the backend's current port.
3. [change] Update the endpoint alias; no IS restart needed.

## Verification

Calls succeed; no new ConnectException.
