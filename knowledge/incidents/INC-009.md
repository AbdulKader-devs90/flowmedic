# INC-009 Cache fails to start: maxEntriesInCache differs between nodes

## Symptoms

After a config change on one node, one distributed cache does not start on is-node-b.

## Root cause

maxEntriesInCache was 50000 on one node and 60000 on the other and on the server array.

## Resolution steps

1. [read] Compare the cache settings on every IS node and on the server array.
2. [change] Make the value the same everywhere.
3. [change] Restart the cache manager, or the node per RB-14.

## Verification

Cache starts on all nodes.
